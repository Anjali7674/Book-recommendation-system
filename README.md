\# 📚 Book Recommendation System



A web-based \*\*Book Recommendation System\*\* that recommends books based on user preferences using collaborative filtering and similarity-based recommendation techniques.



\## 🚀 Features



\* 🔍 Search and select books

\* 📖 Get personalized book recommendations

\* ⭐ Display popular books and ratings

\* 🖼️ Book cover images

\* 🌐 Simple and responsive web interface

\* 🤖 Recommendation using machine learning techniques

\* ⚡ Flask-based backend



\## 🛠️ Technologies Used



\* \*\*Python\*\*

\* \*\*Pandas\*\*

\* \*\*NumPy\*\*

\* \*\*Flask\*\*

\* \*\*HTML\*\*

\* \*\*CSS\*\*

\* \*\*Git \& GitHub\*\*

\* \*\*Git LFS\*\*



\## 🧠 Recommendation Approach



The system uses a \*\*collaborative filtering-based approach\*\* to identify relationships between books and generate recommendations.



The recommendation pipeline includes:



1\. Data collection and preprocessing

2\. Exploratory data analysis

3\. Popularity-based analysis

4\. Creation of a book-user rating matrix

5\. Similarity calculation

6\. Recommendation generation

7\. Flask web application integration

\## ⚙️ Installation \& Setup



\### 1. Clone the repository



```bash

git clone https://github.com/Anjali7674/Book-recommendation-system.git

cd Book-recommendation-system

```



\### 2. Create a virtual environment



```bash

python -m venv venv

```



\### 3. Activate the virtual environment



\*\*Windows:\*\*



```bash

venv\\Scripts\\activate

```



\### 4. Install dependencies



```bash

pip install -r requirements.txt

```



\### 5. Run the application



```bash

python app.py

```



Open the local URL displayed by Flask in your browser.



\## 📊 Dataset



The project uses three datasets:



\* \*\*Books.csv\*\* — Book information and metadata

\* \*\*Users.csv\*\* — User information

\* \*\*Ratings.csv\*\* — User ratings for books



\## 🎯 Project Objective



The objective of this project is to build a recommendation system that can help users discover books they may be interested in based on book-rating patterns and similarity between books.
